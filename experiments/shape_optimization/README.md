Status: EXPERIMENTAL

---

# Purpose

This experiment investigates whether adaptive channel geometries can improve stochastic confined transport compared with fixed geometries.

The objective is NOT to search for a universal geometry.

The objective is:

- maximize transport throughput
- maximize transport stability
- minimize deadlocks
- minimize transport disorder

while keeping the STRUX core untouched.

---

# Current Experimental Result

An evolved geometry generated by optimization outperformed the tested fixed baseline geometries in the current setup.

Current evolved angle sequence:

```text
[30.3, 44.9, 53.3, 58.3, 70.8,
79.7, 89.4, 99.4, 107.6, 121.9]
````

Current benchmark:

| Geometry     | Throughput | Stability (R) |
| ------------ | ---------- | ------------- |
| Evolved      | 1.450      | 0.120         |
| Zig-Zag 120° | 1.120      | 0.250         |
| S-Shape      | 0.850      | 0.400         |

Observed improvement:

* ~30% throughput increase over Zig-Zag
* significant reduction of instability metric R

* compress and organize flow
