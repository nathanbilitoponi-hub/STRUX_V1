\# STRUX Geometric Transition Signature V2



Dataset:

\- SDSS

\- 50,000 galaxies

\- columns: ra, dec, z



Coordinate systems tested:



1\. RA\_DEC\_Z\_raw

2\. XYZ\_approx

3\. XYZ\_Planck18



Goal:

Test whether geometric transition signatures survive coordinate changes.



Family definitions (experimental):



\- 3 = directional / axial state

\- 4 = frame / corridor state

\- 5 = irregularity / defect state

\- 8 = relaxed / quasi-continuous state



Important:

Family 5 currently means irregularity/non-uniformity.

It is NOT interpreted as a physical pentagon.
