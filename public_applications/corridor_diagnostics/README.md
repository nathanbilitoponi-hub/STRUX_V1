\# STRUX Corridor Diagnostics



\## Status



Public-facing application track.



This area contains STRUX demonstrations and prototypes focused on real-world spatial networks.



\## Purpose



STRUX corridor diagnostics studies whether apparent connections in a spatial network are structurally supported, continuous, fragile, redundant, or choke-prone.



The public/product track focuses on practical questions:



\- Which corridors are structurally supported?

\- Which links are fragile or choke-prone?

\- Which paths look connected but have weak geometric support?

\- Which areas behave differently from standard centrality metrics?

\- How does geometric continuity compare with shortest-path centrality?
